정산일기의 데이터는 세 곳에 있을 수 있습니다: 내 폰, 내 구글 캘린더(연동을 켠 경우), 내가 만든 백업 파일. 각각 지우는 방법이 다릅니다.

1. 폰 안의 데이터 지우기

  • 기록 하나: 달력이나 정산 탭에서 기록을 열고 삭제합니다. 구글에 연동돼 있으면 해당 일정도 함께 지워집니다.
  • 전부: 설정 → 위험 구역 → 모든 데이터 지우기. 기록·정산·선정산·거래처·자주 가는 곳·설정·영수증 사진이 지워지고 구글 연결이 끊깁니다. 되돌릴 수 없으니 필요하면 먼저 "백업 파일 만들기"를 하세요.
  • 앱 삭제: 앱을 지우면 폰 안의 데이터는 모두 사라집니다.

2. 구글 캘린더의 일정 지우기

"모든 데이터 지우기"와 "연결 해제"는 구글 캘린더에 이미 올라간 일정을 지우지 않습니다. 남은 일정을 지우려면 구글 캘린더(앱 또는 calendar.google.com)에서 정산일기가 만든 캘린더(라벨 이름과 같은 이름, 설명에 "정산일기"가 적혀 있음)를 찾아 캘린더 자체를 삭제하세요. 캘린더를 삭제하면 그 안의 일정이 모두 지워집니다.

앱에서 지우기 전에 라벨을 삭제하면, 앱이 만든 캘린더는 앱이 함께 지웁니다. 사용자가 원래 갖고 있던 캘린더를 연결한 경우에는 앱이 지우지 않습니다.

3. 구글 계정 접근 끊기

설정 → 구글 캘린더 → 연결 해제를 누르면 앱이 가진 권한을 반납합니다. 또는 구글 계정 → 보안 → 타사 앱 및 서비스에서 "정산일기"의 접근을 삭제할 수 있습니다.

4. 백업 파일

백업 zip 파일은 사용자가 보낸 곳(카카오톡, 드라이브, 컴퓨터 등)에 남습니다. 그곳에서 직접 지워 주세요. 개발자는 백업 파일을 받지 않습니다.
